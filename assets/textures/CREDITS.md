| Файл | Що це | Джерело |

| `cursors/cursor-gold-hover.png` | Та сама натрілка + золотий ореол ПО СИЛУЕТУ — курсор наведення, 43×50 (hotspot `8 7`) | Той самий атлас; ореол домаловується кодом (`shadowBlur`) |
| `cursors/cursor-gray.png` | Срібна натрілка — курсор заблокованих елементів, 43×50 (hotspot `9 7`) | Той самий атлас, права натрілка (x 894…1322 / y 258…800) |

Вирізано `tools/make-cursor.js` (Electron + Canvas): зняття світло-сірого непрозорого
тла атласу flood-fill'ом від країв ділянки → найбільша зв'язна компонента (сама
натрілка) → обрізання по силуету → масштабування. Усі три стани приводяться до
ОДНАКОВОГО канваса: натрілка 36px заввишки + однаковий прозорий запас `PAD = 7` з усіх
боків (файли 43×50). Hotspot = вістря натрілки (`8 7`; у срібної `9 7` — вістря на 1px
правіше), тому вказівка не з'їжджає при переході «звичайний → наведення → заблоковано».
Ореол наведення малюється `shadowBlur` ПО СИЛУЕТУ натрілки, а не круглою плашкою під нею.
Раніше кожен стан мав власний розмір файлу (31×38, 57×64, 30×38) і власний hotspot:
Chromium перемальовував спрайт іншого розміру при наведенні — саме це лишало «силуети»
курсора на кнопках і часом висвічувало системну руку. Працює лише без
`ELECTRON_RUN_AS_NODE`; сам друкує готові рядки `cursor: url(...) X Y` для CSS.

Використання: `src/ui/index.html` і `src/ui/splash.html` — блок «CUSTOM CURSOR»:
`html` → `cursor-gold.png` hotspot `8 7`; інтерактивні елементи та
`::-webkit/moz-range-thumb` → `cursor-gold-hover.png`; заблоковані
(`button[disabled]`, `.disabled`, `.color-option:disabled`) → `cursor-gray.png`.
У hover і disabled першим у списку стоїть варіант стану, другим — базова золота натрілка:
якщо Chromium ще не підготував файл стану, покажеться натрілка гри, а не системний
курсор/біла рука. Власні `cursor: pointer` / `not-allowed` на кнопках (`.buy-dev-btn`)
прибрано — вони перекривали натрілку гри. Раніше всі три стани були inline-SVG у
data-URI — файли замінені.
