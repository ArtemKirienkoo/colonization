## `message-plate.png` — плашка для ігрових повідомлень

| Файл | Що це | Джерело |
|---|---|---|
| `message-plate.png` | Золота текстура-плашка (1918×364) для плаваючих ігрових повідомлень. З вихідного файлу `0e914bc7-a8c0-4bb7-883d-df2ab1e84937.png` (24bpp, золота рамка на чорному тлі) прибрано чорний фон flood-fill'ом від країв + кроп по вмісту, далі вшиту тінь-облямівку знято ерозією (зупинка на золоті). Альфа-канал, прозорий фон | Надано користувачем (джерело уточнити) |

Використання: `src/ui/index.html` — `.game-message` (фон `center / 100% 100% no-repeat`);
внутрішня темна зона текстури — x ≈ 6%…94%, y ≈ 17%…82%, під неї підібраний паддінг
`18px max(56px, 8%)` (на вузькій плашці 56px, на широкій — 8% ширини, щоб текст довгого
повідомлення у два рядки не торкався золотої рамки).

## `buttons/ui-btns/yes-green.png`, `no-red.png` — очищені кнопки Так/Ні

Вшитий чорний контур (темно-коричневий ободок ~5-6px, найтовщий у нижніх кутах) прибрано:
flood-fill темних пікселів від прозорих країв + ерозія темної облямівки (стоп на золотій рамці)
+ видалення дрібних «острівців» підчищених напівтонів. Сам арт (золото/зелень/червоне) не змінювався.

## `buttons/stone-textures/` — кам'яні кнопки (історична довідка)

> 24.09.2026: файли `btn-0.png` … `btn-7.png` прибрано з репозиторію — у коді вже немає
> ні `applyRandomStone()`, ні `--btn-bg`; усі кнопки малюються єдиною текстурою
> `ui-button.png` (`--ui-button` у `:root`). Нижче — довідка про походження.

| Файл | Що це | Джерело |
|---|---|---|
| `btn-0.png` … `btn-7.png` | 8 кнопок-каменів, вирізані з вихідного атласа (PIL: обрізка по силуету каменя + альфа-канал, прозорий фон навколо). Атлас `686f0e79-46c7-4639-963d-6188c84289c4.png` видалено з репозиторію як невикористаний | Надано користувачем (джерело уточнити) |

Використання в UI (`src/ui/splash.html`, `src/ui/index.html`, `src/ui/styles/main.css`):
- CSS: `background-image: var(--btn-bg)` + `mask-image: var(--btn-bg)` — кнопка стає
  ФОРМОЮ каменя (маска по альфа-каналу PNG), без border-radius і прямокутних підкладок.
- JS `applyRandomStone()`: кожна кнопка випадково отримує один із btn-0…btn-7 через
  `--btn-bg`; пере-рандомізація при відкритті модалок та ігрового меню.

Старі матеріали (`medieval-button-pack` від pzUH / OpenGameArt CC0, ambientCG `Bricks097`
та `Rock051` CC0) видалено з репозиторію — більше не використовуються.
