# Colonization - Онлайн мультиплеєр

## Швидкий старт

### Для гравців:

1. **Встанови додаток** (скоро буде доступно)
2. **Відкрий гру** → "Нова гра" → "Мультиплеєр"
3. **Обери сервер**:
   - "Хмарний (онлайн)" - для гри через інтернет
   - "Локальний (LAN)" - для гри в одній мережі
4. **Створи кімнату** або **приєднайся** до існуючої
5. **Поділись кодом** кімнати з другом
6. **Грай!**

### Для розробників (деплой серверу):

Дивись [DEPLOYMENT.md](DEPLOYMENT.md) для детальної інструкції.

## Як це працює

### Архітектура

```
Гравець 1 (додаток) → Хмарний сервер (Railway/Render) ← Гравець 2 (додаток)
```

### Файли:

- `src/main/server-cloud.js` - Сервер для деплою в хмару
- `src/main/server.js` - Локальний сервер (для LAN)
- `src/ui/splash.html` - Клієнт з вибором серверу
- `src/ui/multiplayer.js` - Multiplayer client
- `Procfile` - Конфіг для Railway
- `DEPLOYMENT.md` - Інструкція з деплою

## Варіанти гри

### 1. Онлайн (через інтернет)
- Один раз задеплой сервер на Railway/Render
- Гравці підключаються автоматично
- Коди кімнат для запрошення

### 2. Локальна мережа (LAN)
- Без деплою, сервер запускається автоматично
- Обидва гравці в одній Wi-Fi
- Швидке підключення

## Технології

- **Frontend**: Electron + HTML/CSS/JavaScript
- **Backend**: Node.js + Express + Socket.IO
- **Hosting**: Railway.app / Render.com / Fly.io
- **Real-time**: WebSocket (Socket.IO)

## Розробка

### Встановлення залежностей

```bash
npm install
```

### Запуск локально

```bash
# Запуск гри з локальним сервером
npm start

# Або окремо сервер
npm run start:server
```

### Збірка

```bash
npm run build
```
